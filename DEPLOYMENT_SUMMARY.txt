QUICK START: DEPLOY IN 25 MINUTES
================================================================================

PHASE 1: BACKEND (Fly.io) — 15 minutes
────────────────────────────────────────

1. Set Fly.io secrets (paste your Neon connection strings):

   fly secrets set \
     CONTROL_PLANE_DB_URL="postgres://user:pass@ep-xxx.us-east-2.aws.neon.tech/stonesuite_cp?sslmode=require" \
     PROVISION_ADMIN_DB_URL="postgres://user:pass@ep-xxx-direct.us-east-2.aws.neon.tech/stonesuite_cp?sslmode=require" \
     JWT_SECRET="$(openssl rand -base64 48)" \
     SECRET_ENCRYPTION_KEY="$(openssl rand -base64 32)"

2. Deploy:

   cd backend && fly deploy

3. Verify:

   curl https://stonesuite-backend.fly.dev/api
   # Should return: {"success":true,"message":"...","version":"1.0.0"}


PHASE 2: FRONTEND (Cloudflare Pages) — 5 minutes
──────────────────────────────────────────────────

1. Go to Cloudflare Pages → Create project → Connect to Git
   Select: StoneSuite repo, branch: feat/dynamic-crm-platform

2. Build settings:
   - Framework: Vite
   - Build command: npm run build
   - Build output: dist
   - Root directory: frontend

3. Environment variables:
   - Name: VITE_API_BASE_URL
   - Value: https://stonesuite-backend.fly.dev/api

4. Save and Deploy — wait 2–5 minutes
   Visit: https://stonesuite.pages.dev


PHASE 3: CROSS-ENVIRONMENT CONFIG — 5 minutes
───────────────────────────────────────────────

1. Update backend/fly.toml CORS_ORIGIN to match frontend:

   [env]
     CORS_ORIGIN  = "https://stonesuite.pages.dev"
     FRONTEND_URL = "https://stonesuite.pages.dev"

2. Redeploy backend:

   cd backend && fly deploy

================================================================================
KEY TECHNICAL HIGHLIGHTS
================================================================================

ARCHITECTURE
────────────
• Database-per-tenant isolation (separate Neon DB per customer)
• Control-plane registry (single shared database for routing)
• Stateless Go app (any instance can handle any tenant request)
• JSONB custom fields (≤15 per workflow, validated on every mutation)

SECURITY
────────
• TenantResolver middleware enforces tenant isolation
• RBAC enforcer on all protected routes (resource × action × scope)
• JWT tokens carry tenant_id + user_id (no leakage across tenants)
• Encrypted DSN refs in control plane (tenant DB credentials)

RELIABILITY
───────────
• Control-plane migrations auto-apply (idempotent on every startup)
• Tenant migrations fan-out to all DBs (resume-on-failure)
• Health check gates traffic (404 on /api = auto-restart)
• Fly.io zero-downtime deploys (rolling restart, one VM at a time)

SCALABILITY
───────────
• Separate databases scale independently (heavy customer gets own project)
• Simple connection pool map (30 tenants × 5 conns = 150 connections)
• JSONB + GIN index for custom field queries
• Neon serverless scales idle DBs to zero

API ROUTES AT A GLANCE
================================================================================

PUBLIC (No auth):
  GET    /api                           → Health check
  POST   /api/auth/tenant-login         → Login
  POST   /api/platform/bootstrap        → Create first owner (one-shot, 409)
  GET    /api/onboarding/apply/{token}  → Validate invite
  POST   /api/onboarding/apply          → Submit onboarding form
  POST   /api/onboarding/set-password   → Set password after approval

PLATFORM ADMIN (Auth required):
  GET    /api/platform/tenants          → List all tenants
  POST   /api/platform/tenants          → Create tenant (immediate)
  POST   /api/platform/tenants/{id}/approve  → Approve pending
  POST   /api/platform/tenants/{id}/reject   → Reject pending
  POST   /api/platform/invites          → Send invite email

TENANT-SCOPED (Auth required, RBAC enforced):
  GET    /api/tenant/me                 → Current tenant + user
  GET    /api/tenant/workflows          → List workflows
  POST   /api/tenant/workflows/{id}/fields    → Add custom field
  GET    /api/tenant/roles              → List roles
  POST   /api/tenant/roles              → Create role
  GET    /api/tenant/leads              → List leads
  POST   /api/tenant/leads              → Create lead
  PATCH  /api/tenant/leads/{id}         → Update lead (custom_fields)
  POST   /api/tenant/records/{id}/transition → Move record to state
  (... and many more, see CLAUDE.md)

TROUBLESHOOTING
================================================================================

See detailed guides in:
  → DEPLOY_BACKEND.md section "Troubleshooting"
  → DEPLOY_FRONTEND.md section "Troubleshooting"

Common Issues:
  1. Health check failing
     → Check CONTROL_PLANE_DB_URL is correct
     → Check Neon database exists and is reachable

  2. CORS errors in browser
     → Update CORS_ORIGIN in fly.toml to match frontend URL
     → Redeploy backend

  3. Build failure on Cloudflare Pages
     → Run "npm run build" locally in frontend/ to reproduce
     → Fix TypeScript/linting errors
     → Push to trigger redeploy

  4. Infinite spinner on Workflows/Roles page
     → Check that tenant migrations ran (fly logs | grep "migration")
     → Verify CONTROL_PLANE_DB_URL is set (fly secrets list)
